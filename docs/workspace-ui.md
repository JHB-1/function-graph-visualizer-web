# GV / FGV 작업 공간 UI 계약 v1

GV 웹을 기준으로 두 웹 렌더러의 화면 구조와 조작 규칙을 맞춘다.
계산 엔진, 데이터 모델, 도메인별 기능까지 동일하게 만들지는 않는다.
공통 토큰의 기준은 `src/workspace.css`이며 별도 공통 런타임이나 저장소를 요구하지 않는다.

## 저장소 역할

| 계층 | 역할 |
|---|---|
| core | 메모리 모델, 계산, 증분 갱신, 스타일 값과 상속 |
| web | 브라우저 렌더러, 작업 공간, 웹 파일 입출력, GitHub Pages |
| plugin | 에이전트 도구, 호스트 연결, 인라인 렌더러, 스킬 |
| desktop | 로컬 앱과 플랫폼 어댑터 |

웹 공개 여부와 코어 공개 여부는 독립적이다. 공개 웹에 비공개 코어 소스/헤더를 복사하지 않는다.
각 제품의 기존 plugin/app 저장소를 유지하며 이름 통일을 위한 저장소 재생성은 하지 않는다.

## 셸

- 높이 `100dvh`, 페이지 스크롤 없이 캔버스가 남은 화면 전체 사용
- 데스크톱: 좌측 56px 도구 레일, 300px 설정 패널, 나머지는 캔버스
- 700px 이하: 48px 레일, 최대 300px 오버레이 패널, 캔버스 너비 유지
- 패널 접기/펼치기, 탭 선택으로 해당 패널 열기, Escape로 닫기
- 레일 위 제품 마크, 가운데 세로 탭, 아래 렌더러 UI 밝기와 저장소 링크
- 패널 위 제품명/설명과 닫기, 가운데 독립 스크롤, 아래 실행 상태
- 캔버스 좌상단 줌 배율/확대/축소/맞춤, 패널을 접었을 때 열기 버튼
- 파일 탭에서 파일 출력 메뉴, 해당 제품이 지원하는 이미지/데이터 형식 표시

헤더 최소 높이 69px, 상태 최소 높이 36px, 컨트롤 최소 높이 30px, 모서리 5px을 기본으로 한다.
패널 본문 간격은 위 21px, 좌우 18px이다. 탭 높이는 52px이다.
라이트/다크의 배경, 패널, 레일, 텍스트, 테두리, 보조 텍스트, 입력, 강조색은 공통 토큰을 사용한다.
이는 렌더러 UI 밝기이며 코어 스타일 프리셋이나 문서 편집이 아니다.

## 도메인과 조작

GV의 노드/엣지/배선/분석과 FGV의 함수/수식/축/카메라는 각각 유지한다.
탭 수와 이름은 실제 기능에 맞추되 스타일/파일의 위치와 조작 패턴은 공유한다.
스타일은 유효한 값 변경 시 즉시 반영하고 별도 적용 버튼을 요구하지 않는다.
불완전하거나 잘못된 입력은 마지막 유효 값을 보존하고 오류를 표시한다.
긴 설정은 섹션과 접이식 세부 항목으로 나누며 화면 위에 긴 도구 모음을 추가하지 않는다.

## 접근성과 글꼴

- 세로 `tablist`, `tab`/`tabpanel` ID 연결, 선택 상태, 단일 키보드 탭 진입점
- 위/아래/Home/End 탐색, Enter/Space 선택, 명시적 포커스 표시
- 캔버스 바로 가기와 레이블 있는 줌/맞춤/파일/접기 버튼
- UI/기본 그래프 라벨은 자체 호스팅 Pretendard Variable v1.3.9
- JSON/수식/코드 편집기는 고정폭, 사용자가 명시한 문서 글꼴은 보존
- 폰트 준비 후 초기 문자 측정/맞춤, 이미지 출력에도 기본 글꼴 보존

## 검증/배포

각 저장소에서 데스크톱/모바일 레이아웃, 탭 키보드, 접기/열기, 줌/맞춤,
즉시 스타일 반영, 실제 폰트 로드, 파일 출력, 실행 오류를 검사한다.
제품의 계산/증분 갱신 검사도 유지한다. CI 후 기존 GitHub Pages 주소에서 확인한다.
사용자 진입 주소에 버전 쿼리를 붙이지 않는다.

## FGV 적용

## 공통 파일/복구/항목 흐름, 2026-10-21

- 파일 탭: 새 문서, 파일 열기 (.json), 파일 출력, 자동 저장, 로컬 기록 지우기
- 문서 파일/전체 문서 편집기는 최대 1 MiB, 기존 형식/버전/유한 숫자 검사 후 실제 코어로 기하/원본 ID 검증
- 새 문서/파일/예제 교체 전 미저장 확인, 취소나 실패는 현재 문서/이력/표시 유지
- 자동 저장은 기본 ON, 브라우저 내부 IndexedDB만 사용하며 문서 이름/미저장/저장 결과 표시
- 시작 시 비모달 '이전 작업을 복구할까요?'와 복구/버리기, 선택 전 이전 기록 덮어쓰기 금지
- 자동 저장 OFF는 향후 저장 중단과 해당 자동 복구 기록 삭제, 저장 실패는 현재 그래프 유지
- 제품별 IndexedDB/탭별 sessionStorage 키, Web Locks로 복제 탭 충돌 방지
- 자기 탭 기록 우선/없으면 최근 기록 후보, 복구는 현재 탭에 복사하고 다른 탭 기록 자동 삭제 금지
- 버리기/OFF는 현재 탭 기록만 삭제, 로컬 기록 지우기는 확인 후 해당 제품 전체 기록 삭제
- Web Locks 미제공 환경은 새 탭 키로 충돌을 피하고 이전 키 기록을 복구 후보로 보존
- 항목 탭: 이름·ID 검색, 클릭 선택, 위치 찾기, 스타일 두 번째/파일 마지막 유지
- FGV는 현재 그래프/원본 행 ID/함수 샘플/히스토그램 셀만 노출, 가상 계층 없음
- 위치 찾기는 코어 결과 좌표로 관찰 중심 이동, 최종 기하/행렬/2D 함수 재샘플링은 실제 코어 사용
- 자동 저장과 JSON 파일 출력은 별개, 내보낸 뒤의 변경/편집 중 내용은 미저장으로 표시
- 이 단계는 웹만 수정, plugin/desktop의 고정 빌드는 와이어프레임 수정 버전을 유지

### FGV 적용 세부

- 코어 0.7.0/WASM은 변경하지 않고 웹 셸만 적용
- 공통 CSS는 같은 토큰을 보관하되 Vite의 public 경로 해석을 위해 폰트 URL만 매핑
- 입력/스타일/축·범위/관찰/증분/파일/진단 탭, 수학·집계·기하 계약 유지
- Canvas 2D 라벨은 캔버스의 실제 font-family 상속, 폰트 준비 후 측정과 PNG 합성
- FGV는 현재 SVG 출력 미지원, PNG에 SVG 글꼴 포함을 가장하지 않음
- 스타일 입력 90ms 병합, 성공 후 입력 폼을 다시 만들지 않고 포커스/스크롤 유지
- 잘못된 후보는 이전 그래프 유지, JSON/수식 편집기는 고정폭 유지
