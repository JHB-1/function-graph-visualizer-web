# 중앙 풀 CI와 Pages

`pool-ci.yml`을 중앙 조정기에서만 dispatch합니다. 프로파일은 Linux이며 원본 SHA, 전체 요청 ID와 원본 저장소의 커밋 상태를 보존합니다. 정상인 자체 자원이 바쁘면 대기하고 같은 기능의 다른 PC도 확인한 뒤 사용 가능한 자체 자원이 없을 때만 hosted로 전환합니다.

WASM 런타임, TypeScript, 빌드와 실제 Chromium 검사를 같은 작업에서 실행한 뒤 Pages 아티팩트를 올리고 배포합니다. 별도 hosted 빌드나 push/PR 직접 워크플로는 없습니다. 배포 직전 main SHA와 요청 SHA를 비교해 뒤처진 실행이 최신 웹을 덮어쓰지 못하게 합니다.

기존 공개 `gh-pages`의 고정 커밋 `409e518fdc90bd5a82136874f1622fc878670a1b`에서 이전 해시 자산과 WASM 경로만 보존합니다. 심볼릭 링크와 기존 파일 충돌은 거절합니다. 비공개 코어 원문이나 인증 자료를 웹 빌드에 추가하지 않습니다.

2026-10-22 검증: 실제 Linux 러너 파생 이미지의 WASM 12개, CPU 2개/메모리 4GiB와 기존 보안 제한의 Chromium 18개 통과, Pages 배포 판정/자산 충돌 회귀 2개 통과. 새 GitHub 실행의 배포 성공과 구별합니다.
